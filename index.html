How it works

  1. Make a route

    Walk to each spot and shoot PLACE in the BoxRun menu. The first point is the start and the last is the finish. Test it as you go.

  2. Share the code

    COPY CODE turns the route into one line of text. Paste it in Discord, a group chat or a video description.

    BR1-AQEMQW1iZXIgU3RhaXJzAAZNYXJjdXMGnxiZjQGADKAEogUAAPAVX8AH-AoAoAa6FJ8DtxcMhAEABWo

  3. Race it

    Your friends import the code and run it. The cards at the start and finish show the time to beat, their best, and the hero and souls the time was set with.

What you can make

Speedruns

A loop through the map with a time to beat.

Box runs

Checkpoints at the crates you want to clear. Every crate is up when you start and comes back within seconds.

Movement challenges

Wall jumps, dash jumps and zipline lines you want to land every time.

Rotations

The fastest way between two spots you keep running in real matches.

    Why I made it

    I'm learning Deadlock, and box runs were one of the hardest parts for me because I didn't know the map. It's hard to find the best ones and learn them from videos, and I learn better by doing it in game. Some of my friends are learning too, so I made a way to make our own routes in game and share them.

    Questions

    How do I install it?

    With a mod manager like Grimoire, install it from the GameBanana page and start Deadlock from the manager. Then open the console and type map boxrun_midtown. The GameBanana page also has steps for installing by hand.

    What does it change on my PC?

    BoxRun is one map file you load yourself and play on your own. There's no DLL, no injection and no replaced game file, and nothing changes in normal matches. A mod manager adds the addons lines to Deadlock's gameinfo.gi file, as it does for every mod.

    Do I need to keep anything running beside the game?

    No. Everything happens in the in-game menu.

    Where are my routes saved?

    On your PC, in the storage of the game's built-in browser, through a small BoxRun page at save.boxrun.gg. Nothing is uploaded. Saving needs the internet; offline, new routes and times last until you quit. Route codes work either way.

    Can I race my friends live?

    Not live: Deadlock doesn't let players join custom servers. You race by sharing a route code and beating each other's times.

    Are there leaderboards?

    Not yet. Each route has a time to beat and your own best. An online library of community routes, with leaderboards, is the next big thing on the list.

    Does the hero matter?

    Use any hero. Times remember the hero and whether you gave yourself max souls, so you can compare like with like.

    What happens when the map changes in a patch?

    BoxRun carries its own copy of the Deadlock map, so after a big map change it needs an update to match. The update goes up on the GameBanana page.

    Where do I report a bug or share a route?

    In the BoxRun Discord. Post route codes there, and say what broke and what you were doing when it happened.

    How do I remove it?

    Remove it in your mod manager, or delete the addon file the install notes name. To clear your saved routes first, type boxrun_clear_saves in the console while on the map.
